Koşum: flutter run -d chrome --web-header=Cross-Origin-Opener-Policy=same-origin
--web-header=Cross-Origin-Embedder-Policy=require-corp --dart-define=ENABLE_FLUTTER_DRIVER=true
--dart-define=DURUM_VITRINI=true --print-dtd

flutter_driver_command -> screenshot ÇAĞRILDI (enableFlutterDriverExtension() bu
koşumda GERÇEKTEN etkindi -- bir önceki denemede ENABLE_FLUTTER_DRIVER eksikti,
bu ölçüm o hatayı düzeltip TEKRARLANDI).

GERÇEK HATA METNİ:
  ext.flutter.driver: (-32000) Server error
  {"exception":"Unsupported operation: StdIOUtils._getStdioOutputStream", ...
   package:flutter_driver/src/extension/extension.dart 394:5  [_log]
   ...}

Kök neden: flutter_driver'ın screenshot komutu kendi iç loglaması için
dart:io stderr'e erişmeye çalışıyor; web (dart2js/DDC) çalışma zamanında
`dart:io` stdio desteklenmiyor ("Unsupported operation"). Bu, Z6'nın
belgelediği "web'de flutter_driver ekran görüntüsü desteklenmez" sınırının
FİİLEN GÖZLEMLENMİŞ halidir (docs.flutter.dev/ai/mcp-server: "the
flutter_driver extension isn't supported on web builds, so finder-based
commands like screenshots and taps aren't available there").
